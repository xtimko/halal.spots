# Halal Spots — Москва

Интерактивная карта мест из личного списка: адрес, часы работы и оценка в звёздах.

Открыть: `index.html` в браузере (одна страница, без сборки). Для ссылки на телефоне включите
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

- Данные — массив `PLACES` в `index.html`.
- Цвет метки: зелёный — обычное место, синий — морепродукты, оранжевый — не всё меню халяль.
- Карта — Яндекс Карты (JS API 2.1, ключ в `<script>` внизу `index.html`). Метки ставятся по
  примерным координатам и уточняются геокодером Яндекса по адресу; результат кешируется в браузере,
  поэтому запросы к геокодеру уходят только при первом открытии.
- Часы и рейтинги взяты из 2ГИС / Яндекс Карт на октябрь 2026 — актуальные данные открываются по
  ссылкам «Яндекс Карты» / «2ГИС» в карточке.
